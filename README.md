# Сахар — дневник глюкозы

Мобильный PWA для записи уровня глюкозы. Работает без backend: измерения хранятся только в IndexedDB на устройстве, после первой загрузки приложение и экспорт работают офлайн.

## Возможности

- Три типа измерений: **«Натощак»**, **«1 ч после еды»**, **«2 ч после еды»**.
- Быстрый ввод значения с запятой, например `5,6`; дата и время фиксируются автоматически.
- Обзор последнего значения и статистики за 7 дней.
- История по дням с удалением после подтверждения.
- Пресеты периодов и несколько пользовательских диапазонов, объединяемых без дублей.
- SVG-график фактических измерений, touch/keyboard-подсказки и табличное представление.
- Настоящий `.xlsx`-отчёт текущего периода с листами «Измерения» и «Сводка», настройками печати A4, закреплённым заголовком и фильтром.
- Установка на домашний экран iPhone, safe-area и offline service worker.

Приложение показывает только фактические значения и описательную статистику. Оно не ставит диагнозы и не заменяет рекомендации врача.

## Локальный запуск

Нужен Node.js 24 или новее.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173/sugar/`.

Production-сборка:

```bash
npm run build
npm run preview
```

Откройте `http://localhost:4173/sugar/`.

## Проверки

```bash
npm test
npm run test:e2e:install
npm run test:e2e
```

- Vitest проверяет доменную логику, локальные даты, IndexedDB, DOM-сценарии, график и содержимое XLSX после roundtrip.
- Playwright проверяет мобильный сценарий 390×844, сохранение после reload, фильтры, график/таблицу, удаление, download и production offline.
- Для повторной генерации иконок используйте `npm run icons`.

## Публикация на GitHub Pages

Репозиторий уже настроен на `maksimsidukov/sugar`, а base path — `/sugar/`.

1. Добавьте файлы в Git, создайте commit и отправьте ветку `main`:

   ```bash
   git add .
   git commit -m "feat: add glucose diary PWA"
   git push -u origin main
   ```

2. В GitHub откройте **Settings → Pages** и выберите **Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` запустит unit/DOM-тесты, соберёт `dist` и опубликует Pages. E2E временно отключены в CI, но их можно запустить локально командами из раздела «Проверки».
4. Готовый адрес: **https://maksimsidukov.github.io/sugar/**.

Если репозиторий будет переименован или подключён custom domain, обновите `base` в `vite.config.ts`, `start_url`/`scope` в manifest, ссылки в `index.html`, URL в Playwright config и этот адрес.

## Установка на iPhone

1. Откройте опубликованный сайт именно в **Safari**.
2. Нажмите **«Поделиться» → «На экран “Домой”»**.
3. Запустите «Сахар» с домашнего экрана.
4. После первого открытия дождитесь сообщения «Приложение готово работать офлайн». Затем записи, график и XLSX-экспорт будут доступны без сети.

При появлении новой версии внизу появится кнопка **«Обновить»**.

## Данные и отчёты

- Записи находятся в IndexedDB `sugar-diary`, object store `measurements`. Они не отправляются на сервер; аналитики и внешних шрифтов нет.
- Удаление данных сайта, приватный режим или очистка хранилища iOS могут удалить дневник. Регулярно сохраняйте XLSX, если нужна внешняя копия.
- Кнопка с иконкой загрузки в «Истории» скачивает отчёт именно для выбранного периода. На iPhone файл можно сохранить в **Files**, открыть в Numbers/Excel и распечатать.
- В Excel числовой формат хранится как `0.0`; десятичный разделитель отображается согласно региональным настройкам Excel.

## Стек

TypeScript, Vite, IndexedDB (`idb`), vite-plugin-pwa/Workbox, SVG, ExcelJS (lazy-loaded), Vitest + jsdom + fake-indexeddb, Playwright.
